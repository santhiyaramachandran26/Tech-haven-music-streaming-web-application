# Tech-haven-music-streaming-web-application
🎧 A full-stack music streaming web application featuring seamless audio playback, real-time track search, interactive player controls, and custom user playlists.Tech Haven is a sleek, modern music streaming web application designed to offer an immersive listening experience. It features continuous global audio playback, user authentication, playlist management, and a responsive user interface across all devices.
## 📌 Project Overview

**Tech Haven** is an interactive web platform that allows users to discover, stream, and organize their favorite music seamless in real time. 

### Key Highlights:
* **Persistent Audio Engine:** Uninterrupted audio playback featuring play, pause, skip, seek, and volume control that stays active while navigating the site.
* **Music Discovery & Search:** Instant filter and search capability by song title, artist, or album genre.
* **User Accounts & Libraries:** Secure user authentication allowing listeners to create customized playlists and save favorite tracks.
* **Responsive UI/UX:** Dark-mode themed, clean aesthetic optimized for desktop, tablet, and mobile views.
